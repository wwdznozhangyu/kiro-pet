Kiro Pet 桌宠 🟣

四六级 · 专八 · 雅思 · 托福 单词学习桌宠 — 浏览器交互式 Demo

GitHub 仓库 · 使用文档

完整应用是一个 Electron 桌面程序（透明置顶桌宠 + 托盘 + 开机自启）， 浏览器里无法还原这些系统能力。本页用相同的萌宠形象与单词卡逻辑，演示核心交互。

移动鼠标 → 眼睛会追踪你；点击 Kiro → 弹出单词卡

    本项目做了什么

    🐾 桌宠

    透明无边框置顶、鼠标拖拽、眼睛追踪 + 眨眼、随机漫游/跳跃、双击弹卡、右键设置菜单（macOS 为 Control+点击）。

    🗂 单词卡片

    单词 + 英/美音标 + 发音喇叭、三条按考试优先级排序的释义（带词性）、2–3 个同义词；圆角白底 + 浅蓝阴影。

    📚 词库

    内置四六级/专八/雅思/托福核心词库；支持 JSON/CSV 导入；提供可扩至 6000 词的构建与校验管线。

    📦 打包

    Electron + Vite + React + TS；electron-builder 输出 Windows .exe 与 macOS .dmg/.app；可选开机自启。

    ✅ 测试

    词库逻辑 57/57 单元测试通过；提供 schema 校验脚本可用于提交/CI 门禁。

    🔗 获取

    git clone https://github.com/wwdznozhangyu/kiro-pet.git
    npm install && npm run dev 本地运行；npm run dist:win / dist:mac 打包。
